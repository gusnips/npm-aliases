# @gusnips/assinafy

Same package as [`assinafy`](https://www.npmjs.com/package/assinafy). It installs `assinafy` and re-exports all of it, so both names give you the same code.

```ts
import { AssinafyClient } from "@gusnips/assinafy"; // or from "assinafy"
```

Docs: https://github.com/gusnips/assinafy#readme
Source and issues: https://github.com/gusnips/assinafy
