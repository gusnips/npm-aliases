# @gusnips/sherlocker

Same package as [`sherlocker`](https://www.npmjs.com/package/sherlocker). It installs `sherlocker` and re-exports all of it, so both names give you the same code.

```ts
import { SherlockerClient } from "@gusnips/sherlocker"; // or from "sherlocker"
```

Docs: https://github.com/gusnips/sherlocker#readme
Source and issues: https://github.com/gusnips/sherlocker
