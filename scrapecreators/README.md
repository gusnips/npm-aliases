# @gusnips/scrapecreators

Same package as [`scrapecreators`](https://www.npmjs.com/package/scrapecreators). It installs `scrapecreators` and re-exports all of it, so both names give you the same code.

```ts
import { ScrapeCreatorsClient } from "@gusnips/scrapecreators"; // or from "scrapecreators"
```

Docs: https://github.com/gusnips/scrapecreators#readme
Source and issues: https://github.com/gusnips/scrapecreators
