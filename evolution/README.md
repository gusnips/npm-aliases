# @gusnips/evolution

Same package as [`evolution-api-sdk`](https://www.npmjs.com/package/evolution-api-sdk). It installs `evolution-api-sdk` and re-exports all of it, so both names give you the same code.

```ts
import { EvolutionClient } from "@gusnips/evolution"; // or from "evolution-api-sdk"
```

Docs: https://github.com/gusnips/evolution-api-sdk#readme
Source and issues: https://github.com/gusnips/evolution-api-sdk
