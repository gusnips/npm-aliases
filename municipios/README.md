# @gusnips/municipios

Same package as [`municipios-brasil`](https://www.npmjs.com/package/municipios-brasil). It installs `municipios-brasil` and re-exports all of it, so both names give you the same code.

```ts
import { listarEstados } from "@gusnips/municipios"; // or from "municipios-brasil"
```

`@gusnips/municipios/dados` works too, the same as `municipios-brasil/dados`.

Docs: https://github.com/gusnips/municipios-brasil#readme
Source and issues: https://github.com/gusnips/municipios-brasil
