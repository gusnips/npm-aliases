# @gusnips/sociavault

Same package as [`sociavault`](https://www.npmjs.com/package/sociavault). It installs `sociavault` and re-exports all of it, so both names give you the same code.

```ts
import { SociaVaultClient } from "@gusnips/sociavault"; // or from "sociavault"
```

Docs: https://github.com/gusnips/sociavault#readme
Source and issues: https://github.com/gusnips/sociavault
