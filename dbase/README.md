# @gusnips/dbase

Same package as [`dbase-sdk`](https://www.npmjs.com/package/dbase-sdk). It installs `dbase-sdk` and re-exports all of it, so both names give you the same code.

```ts
import { DbaseClient } from "@gusnips/dbase"; // or from "dbase-sdk"
```

The `dbase` name on npm is a different package, by someone else.

Docs: https://github.com/gusnips/dbase#readme
Source and issues: https://github.com/gusnips/dbase
