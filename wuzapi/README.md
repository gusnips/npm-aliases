# @gusnips/wuzapi

Same package as [`wuzapi`](https://www.npmjs.com/package/wuzapi). It installs `wuzapi` and re-exports all of it, so both names give you the same code.

```ts
import WuzapiClient from "@gusnips/wuzapi"; // or from "wuzapi"
```

Docs: https://github.com/gusnips/wuzapi-node#readme
Source and issues: https://github.com/gusnips/wuzapi-node
