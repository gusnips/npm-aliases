# @gusnips/targetdata

Same package as [`targetdata`](https://www.npmjs.com/package/targetdata). It installs `targetdata` and re-exports all of it, so both names give you the same code.

```ts
import { TargetDataClient } from "@gusnips/targetdata"; // or from "targetdata"
```

Docs: https://github.com/gusnips/targetdata#readme
Source and issues: https://github.com/gusnips/targetdata
