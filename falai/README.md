# @gusnips/falai

Same package as [`@falai/agent`](https://www.npmjs.com/package/@falai/agent). It installs `@falai/agent` and re-exports all of it, so both names give you the same code.

```ts
import { falai } from "@gusnips/falai"; // or from "@falai/agent"
```

Docs: https://falai.dev
Source and issues: https://github.com/falai-dev/agent
