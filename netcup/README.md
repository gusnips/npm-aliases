# @gusnips/netcup

Same package as [`netcup-sdk`](https://www.npmjs.com/package/netcup-sdk). It installs `netcup-sdk` and re-exports all of it, so both names give you the same code.

```ts
import { NetcupClient } from "@gusnips/netcup"; // or from "netcup-sdk"
```

Docs: https://github.com/gusnips/netcup#readme
Source and issues: https://github.com/gusnips/netcup
